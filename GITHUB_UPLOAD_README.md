# Bharat Navigator — GitHub Upload Package

This package is prepared for source upload.

Included:
- `src/` application source, including `src/main.tsx`
- `server.ts`
- `package.json` / `package-lock.json`
- Vite/TypeScript configuration
- Firebase/Supabase project configuration files present in the source package
- Firestore rules and security specification

Excluded intentionally:
- `.env`
- `.env.local`
- `node_modules/`
- `.git/`
- `dist/`

Before making the repository public, review Firebase configuration and any other project configuration for secrets.
